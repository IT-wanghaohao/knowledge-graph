# 知枝-无限制思维导图

**知枝是一款面向个人使用的本地知识图谱和思维导图工具。** 你可以用父子层级把想法整理成大纲，再用关系线连接不同分支里的知识点。它适合整理读书笔记、梳理技术专题和拆解项目计划。

## 项目特点

- **本地保存**。在浏览器里编辑，无需注册。图谱自动保存在当前浏览器，生产版完成首次缓存后也能离线使用。
- **节点数不限额**。应用层面不设节点数量配额。图谱大了，可以用分支折叠、聚焦、搜索和小地图定位。流畅度取决于设备和同屏展开的节点数。
- **数据可以带走**。整张图或单条分支都能导出。比如从完整的读书图谱里只导出一章，折叠和屏幕外的后代也会一并导出。
- **大纲与关系共用一份数据**。用键盘批量录入，用画布查看和调整关系。多个分支还能引用同一份节点内容。

## 当前功能


| 功能         | 可以做什么                                                                                                         |
| ------------ | ------------------------------------------------------------------------------------------------------------------ |
| 节点编辑     | 双击节点在卡片内编辑，支持多行标题、快捷新建、插入上级、同级排序和右键菜单                                         |
| 拖拽与排版   | 移动父节点时带动整条分支。落到其他节点、同级间隙或父子连线上时，有相应的落点提示。可按节点尺寸和层级自动整理整张图 |
| 内容与关系   | 添加备注、来源链接和标签，建立命名的跨分支关系，引用已有节点，链接到另一张图谱                                     |
| 浏览与管理   | 在图谱和大纲之间切换，按内容搜索和标签筛选，折叠时查看后代数量，管理多张图谱                                       |
| 批量操作     | 复制、剪切和粘贴分支，也可以直接粘贴多行缩进文本来生成子树                                                         |
| 保存与恢复   | 本地自动保存、撤销和重做。可以保存版本，并从旧版本恢复指定分支                                                     |
| 导入与导出   | 导入知枝 JSON、Markdown 大纲和缩进文本。将整图或选中分支导出为 JSON、Markdown、PNG                                 |
| 本机 AI 整理 | 可选功能。连接本机 Ollama，把提交的文本整理成大纲，确认预览后再加入图谱                                            |

**文件怎么选**


| 格式     | 用途                                                               |
| -------- | ------------------------------------------------------------------ |
| JSON     | 备份后重新导入，保留节点、备注、标签、层级、布局及导出范围内的关系 |
| Markdown | 和文档、笔记等工具交换文字大纲                                     |
| PNG      | 分享图谱或分支的图片                                               |

## 快速开始

需要 Node.js 24 或更高版本。获取项目后，在项目目录运行以下命令。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址。第一次进入会看到一张示例图谱，也可以通过左侧的「新建图谱」开始整理自己的内容。

### 常用快捷键


| 操作                                    | 快捷键                                              |
| --------------------------------------- | --------------------------------------------------- |
| 保存当前标题 / 新增同级节点             | `Enter`。在标题编辑框内保存，选中节点时新增同级节点 |
| 新增子节点 / 插入上级节点               | `Tab` / `Shift+Tab`                                 |
| 在标题内换行                            | `Shift+Enter`                                       |
| 上移 / 下移同级节点                     | `Alt+↑` / `Alt+↓`                                 |
| 删除当前节点并保留子节点 / 删除整条分支 | `Delete` / `Shift+Delete`                           |
| 复制 / 剪切 / 粘贴分支                  | `Ctrl/Cmd+C` / `Ctrl/Cmd+X` / `Ctrl/Cmd+V`          |
| 折叠或展开分支                          | `Ctrl/Cmd+/`                                        |

### 离线使用与备份

```sh
npm run build
npm run preview
```

首次打开生产预览并完成缓存后，可以在断网时重新打开同一地址。浏览器数据按浏览器配置和站点地址隔离。换浏览器、换端口或清理站点数据前，可以导出 JSON 备份。

### 本机 AI 整理

将 `OLLAMA_NO_CLOUD` 设为 `1` 后启动本机 Ollama。在知枝打开「AI 整理」，输入已下载的模型名称和待整理文本。知枝连接本机的 `127.0.0.1:11434`，预览大纲后由你决定是否加入图谱。

如果 Ollama 拒绝浏览器访问，可以将 `OLLAMA_ORIGINS` 设为知枝当前打开的地址，然后重启 Ollama。

## 开发

使用 Vue 3、TypeScript 和 Vite。Vue Flow 提供画布能力，独立的图谱模型负责节点、层级和导出。Yjs 处理编辑事务和撤销，IndexedDB 保存浏览器中的图谱。

```sh
npm test
npm run check
npm run build
```
